# Data Dictionary

Documentation for the processed data files in `public/data/processed/`.

All files are generated by `analysis/process_annotations.py` from the SONYC-UST v2.3 dataset
(DOI: 10.5281/zenodo.3966543). `clip-index.json` is generated separately by `scripts/upload_to_r2.sh`.

---

## `hourly-stats.json`

Sound prevalence and estimated loudness by borough and hour of day.

**Top-level structure:**

```json
{
  "meta":       { "generated": "...", "source": "annotations.csv", "n_rows": 62022 },
  "global":     { "0": { ... }, "1": { ... }, ..., "23": { ... } },
  "by_borough": { "1": { "0": { ... }, ... }, "3": { ... }, "4": { ... } },
  "coverage":   { "1": { "0": 1842, ... }, ... }
}
```

`global` aggregates all boroughs. `by_borough` is keyed by borough code:
`"1"` = Manhattan, `"3"` = Brooklyn, `"4"` = Queens.

`coverage` maps borough → hour → annotation count (useful for flagging low-data hours).

**Per-hour entry:**

| Field | Type | Description |
|-------|------|-------------|
| `prevalence` | object | Fraction of annotations (0.0–1.0) where each coarse class was marked present |
| `db` | number | Estimated loudness — **not a real measurement**. Energy-weighted average derived from prevalence rates using reference dB levels per class. See `process_annotations.py`. |
| `dominant` | string | Coarse class with the highest prevalence this hour |
| `n_annotations` | integer | Annotation rows contributing to this entry |

**`prevalence` keys:** `engine`, `machinery`, `impact`, `saw`, `alert`, `music`, `voice`, `dog`

**Source columns in `annotations.csv`:**

| Column | Values | Description |
|--------|--------|-------------|
| `hour` | 0–23 | Hour of day |
| `borough` | 1, 3, 4 | Borough code (Manhattan, Brooklyn, Queens) |
| `annotator_id` | int | 0 = ground truth (SONYC team); positive = Zooniverse volunteer |
| `1_engine_presence` | 1 / 0 / -1 | 1=present, 0=absent, -1=unlabeled (annotator skipped this group) |
| `2_machinery-impact_presence` | 1 / 0 / -1 | same |
| `3_non-machinery-impact_presence` | 1 / 0 / -1 | same |
| `4_powered-saw_presence` | 1 / 0 / -1 | same |
| `5_alert-signal_presence` | 1 / 0 / -1 | same |
| `6_music_presence` | 1 / 0 / -1 | same |
| `7_human-voice_presence` | 1 / 0 / -1 | same |
| `8_dog_presence` | 1 / 0 / -1 | same |

Note: presence = 1 means "this sound class was present somewhere in the 10-second clip," not
that it was dominant or easily audible. Many clips have multiple co-labeled classes.

## `sensors.json`

One entry per unique SONYC sensor. 56 sensors total.

| Field | Type | Description |
|-------|------|-------------|
| `sensor_id` | string | Unique sensor identifier |
| `lat` | number | Latitude, quantized to block level (not exact placement) |
| `lng` | number | Longitude, quantized to block level |
| `borough` | integer | 1=Manhattan, 3=Brooklyn, 4=Queens |
| `borough_name` | string | `"Manhattan"`, `"Brooklyn"`, or `"Queens"` |
| `block` | string | Block identifier from the dataset |
| `n_clips` | integer | Number of clips recorded by this sensor |

Coverage is heavily skewed toward Manhattan (32 sensors within 1km of Washington Square).
Brooklyn has moderate coverage; Queens has a single sensor near Elmhurst/Rego Park (sensor 45)
with no data between 12am–5am.

## `clip-index.json`

Maps SONYC fine-grained class names to arrays of public MP3 URLs on Cloudflare R2.
Generated by `scripts/upload_to_r2.sh` after the audio pipeline runs.

```json
{
  "small-sounding-engine": [
    "https://pub-64ca4e71668742ceab6b2c679a8ff9ca.r2.dev/small-sounding-engine-01.mp3",
    "https://pub-64ca4e71668742ceab6b2c679a8ff9ca.r2.dev/small-sounding-engine-02.mp3"
  ],
  "jackhammer": [ ... ],
  ...
}
```

**23 fine-grained classes across 8 coarse groups:**

```
engine:    small-sounding-engine, medium-sounding-engine, large-sounding-engine
machinery: rock-drill, jackhammer, hoe-ram, pile-driver
impact:    non-machinery-impact
saw:       chainsaw, small-medium-rotating-saw, large-rotating-saw
alert:     car-horn, car-alarm, siren, reverse-beeper
music:     stationary-music, mobile-music, ice-cream-truck
voice:     person-or-small-group-talking, person-or-small-group-shouting,
           large-crowd, amplified-speech
dog:       dog-barking-whining
```

Clips were selected from ground-truth annotations (`annotator_id=0`), scored by Gemini
caption keyword match and prominence (`analysis/analyze_captions.py`). Up to 10 clips per class,
loudness-normalized to −16 LUFS.

7 sparse classes have no audible keyword-matched clips and fall back to Web Audio synthesis
in the app: `car-alarm`, `ice-cream-truck`, `large-crowd`, `hoe-ram`, `pile-driver`,
`amplified-speech`, `large-rotating-saw`.
